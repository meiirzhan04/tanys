# Tanys 1.0 — отчёт по нагрузке и качеству подбора на 320 участниках (`#61`)

Воспроизводимая проверка нагрузки, конкурентного бронирования и релевантности рекомендаций на размере реального IT-митапа (≥ 300 участников в одном событии). Скрипт проверки: [`tests/load/meetup-load-check.mjs`](../tests/load/meetup-load-check.mjs), автотест: [`tests/load/meetup-load-check.test.mjs`](../tests/load/meetup-load-check.test.mjs).

## 1. Конфигурация и согласованный пик нагрузки

| Параметр | Значение |
| --- | --- |
| Размер выборки (одно событие) | **320 синтетических участников** (без реальных ПДн; `find_job: 58`, `hire: 53`, `find_mentor: 52`, `be_mentor: 52`, `find_cofounder: 53`, `exchange_experience: 52`; `0` ошибок схемы) |
| Пик одновременных входов (`POST /auth/challenges` + `/sessions`) | **40 запросов**, параллельность **20** |
| Пик одновременных запросов подбора (`GET /events/:id/recommendations`) | **120 запросов**, параллельность **24** (на пуле 320 анкет) |
| Конкурентная проверка двойных броней (`PATCH /events/:id/meetings/:id`) | **20 одновременных подтверждений** пересекающегося слота одного участника |
| Среда контрольного прогона | Node.js `v24.19.0`, локальный HTTP-стенд с продакшен-движком `recommend()` (`server/src/matching/recommend.ts`) |
| Критерии приёмки `#61` | `p95 подбора < 3000 мс`, `0` подтверждённых двойных броней, минимум `3/5` релевантных на каждой контрольной анкете |
